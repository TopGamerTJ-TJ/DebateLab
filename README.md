DebateLab is a full-stack competitive debate preparation platform designed to help debaters of all skill levels improve their research, content generation, and round performance.

Features
Format-Specific Tools: Tailored workspaces for Parliamentary, Public Forum, Model UN, and Model Congress.
AI-Powered Content Generation: Generate robust contentions, research, and speeches using advanced AI models.
Practice Simulations: Simulate full debate rounds against an AI opponent with real-time feedback and judge evaluation.
Analytics Dashboard: Track your progress, win rates, and speaking performance metrics through an integrated AI Coach.
Tournament & Project Management: Manage your research projects, tournament schedule, and debate documents in one organized hub.
Community Forum: Connect with other debaters to share strategies, exchange resources, and discuss resolution topics.
Technical Stack
Frontend: React, Tailwind CSS, Framer Motion
Components: Radix UI primitives, Lucide React icons
State & Data: TanStack Query for efficient server-state management
Integrations: Advanced AI models for research, coaching, and content generation
Getting Started
(Note: If you are deploying this from a Base44 platform project, most configuration is handled automatically by the environment.)

Authentication: The application supports email/password and social login (Google OAuth) through the integrated auth flow.
Navigation: Use the dashboard to jump into your active projects, practice rounds, or the debate wiki.
Practice: Navigate to the "Practice Round" section to start a simulation or visit the "AI Coach" to review your performance metrics.
Roadmap & Support
DebateLab is an ongoing project designed to support the competitive debate community. For issues, feature requests, or to contribute to the platform, please reach out via the in-app support tools or open an issue on GitHub.
